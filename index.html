2. Твой ритм жизни

Формула Миффлина — Сан Жеора рассчитывает ориентир для взрослых; реальные затраты энергии индивидуальны. Расчёт не подходит для детей и подростков. При беременности, кормлении, расстройствах пищевого поведения или заболеваниях, влияющих на питание, цели лучше согласовать со специалистом. Опрос не учитывает все особенности здоровья.

Твой результат

Заполни анкету слева, чтобы увидеть персональные ориентиры по калориям, белкам, жирам и углеводам.

Метод: Mifflin–St Jeor · ISSN (белок) · National Academies (БЖУ).

Это отправная точка: наблюдай тенденцию веса 2–4 недели. Цели можно изменить в любой момент через «Аккаунт и настройки».

Аккаунт и настройки

У каждого аккаунта отдельные записи. Гостевые записи доступны только на этом устройстве. Перед переходом в облако сделай экспорт JSON.

Профиль и цели

Калории и БЖУ можно установить вручную либо пересчитать по анкете. Старый план не меняется без нажатия «Сохранить мой план».

Мой аккаунт и облако

Гостевой режим: данные только на этом устройстве.

Для каждого пользователя используется отдельная запись с RLS. Никогда не вставляй пароль базы данных, secret key или service_role key. При конфликте версий экспортируй JSON перед восстановлением данных.
